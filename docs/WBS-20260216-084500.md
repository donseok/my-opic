## 6. 리스크 및 가정사항

### 가정사항
- 개발 인력이 해당 기술 스택(HTML/CSS/JS, Node.js, Express, SQLite)에 충분한 경험이 있음
- Gemini API Key 발급 및 환경 설정이 프로젝트 시작 전 완료됨
- Google Stitch를 통한 UI 디자인 산출물이 HTML/CSS로 내보내기 가능함
