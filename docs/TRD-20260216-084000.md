## 1. 기술 요약 (Executive Summary)

OPIc Master는 OPIc 시험 대비 종합 학습 웹+모바일 앱으로, 클라이언트 사이드 중심의 SPA(Single Page Application) 아키텍처를 채택한다. 단일 Express 서버가 SPA 웹 프론트엔드와 REST API를 모두 서빙하며, Flutter 모바일 앱이 같은 API를 사용하는 구조이다.

핵심 기술 결정:
1. **모놀리식 아키텍처**: 프론트엔드+백엔드 단일 프로젝트, `npm start` 한 번으로 실행
2. **Gemini API 프록시 + 멀티모달**: 텍스트 평가 + 오디오 분석 모두 지원 (gemini-2.5-flash)
3. **SQLite 파일 기반**: better-sqlite3 동기식 API, WAL 모드, 23개 테이블
4. **Vanilla JS SPA**: 프레임워크 없이 순수 JS 모듈 구조, hash 기반 라우팅
5. **Flutter 크로스 플랫폼**: 동일 REST API로 Android/iOS 앱 제공
6. **라이트 모드 디자인**: 흰색+스카이블루(#0284C7) 테마, Pretendard 폰트

### 3.2 계층별 설명
| 계층 | 설명 | 핵심 컴포넌트 |

| Presentation Layer (Mobile) | Flutter. Provider 상태 관리 | 5탭 네비 + AppBar 메뉴 |

| Data Access Layer | better-sqlite3 동기식. 트랜잭션 지원 | database.js 싱글턴, 23개 테이블 |
| External Integration | Gemini API 멀티모달 (텍스트+오디오) | evaluateAnswers(), analyzeVoiceRecording() |

### 3.3 핵심 데이터 흐름

**1. 모의시험 → AI 피드백:**
```
POST /exam/start (5문제 구성) → 답변 입력 → POST /exam/sessions (저장)
→ POST /feedback/evaluate (Gemini AI 평가) → skill_assessments 5축 점수 저장
```

**2. 스크립트 빌더:**
```
초안 작성 → POST /scripts/generate (AI 생성) → POST /scripts/:id/refine (AI 개선)
→ 플래시카드 암기 → 문장별 발음 연습
```

**3. SRS 간격반복:**
```
POST /srs/seed (답변가이드→SRS 항목) → GET /srs/due (오늘 복습)
→ POST /srs/review (SM-2 간격 업데이트)
```

**4. 학습 플랜:**
```
GET /study-plan/today (없으면 자동 생성) → 약점 분석 기반 태스크 목록
→ 태스크 완료 체크 → 완료율 갱신
```

- **파일명**: `opic_master.db` (프로젝트 루트, gitignore)

- **테이블 수**: 23개
- **인덱스 수**: 19개

## 5. API 명세 (API Specification)

### 5.1 공통 사항
- **Base URL**: `/api/v1`
- **인증**: 없음 (단일 사용자 로컬 앱)
- **공통 헤더**: `Content-Type: application/json`
- **Body 크기 제한**: 10MB (음성 데이터 포함)
- **Rate Limit**: 분당 100회
- **에러 응답**: `{ error: true, code: 'ERROR_CODE', message: '...' }`

### 5.2 엔드포인트 목록 (15개 라우터)

| 라우터 | 마운트 경로 | 주요 엔드포인트 |
|--------|-----------|---------------|
| topics | /topics | `GET /` 주제 목록, `PUT /selection` 선택 저장 |
| levels | /levels | `GET /` 레벨 목록 |
| settings | /settings | `GET /` 설정 조회, `PUT /` 설정 저장 |
| questions | /questions | `GET /` 질문 목록(필터), `GET /:id/guide` 답변 가이드 |
| exam | /exam | `POST /start` 시험 시작, `POST /sessions` 결과 저장, `GET /sessions` 이력 |
| feedback | /feedback | `POST /evaluate` AI 피드백 요청, `GET /:sessionId` 피드백 조회 |
| dashboard | /dashboard | `GET /stats` 통계, `GET /trends` 추이 |
| voice | /voice | 음성 녹음 저장/조회/분석 |
| scripts | /scripts | CRUD + `POST /generate` AI 생성, `POST /:id/refine` AI 개선 |
| studyPlan | /study-plan | `GET /today` 오늘 플랜, 태스크 완료 처리 |
| srs | /srs | `POST /seed` 항목 생성, `GET /due` 오늘 복습, `POST /review` 리뷰 |
| studySessions | /study-sessions | `POST /start` 세션 시작, `PUT /:id/end` 세션 종료 |

## 10. 기술 리스크

| ID | 리스크 | 영향도 | 대응 방안 |
|----|--------|--------|----------|
| TR-001 | Gemini API 무료 티어 한도 초과 | HIGH | Rate Limit 적용, 사용 횟수 추적 |
| TR-002 | Gemini API 응답 형식 불일치 | MEDIUM | JSON 파싱 검증, 폴백 템플릿, raw_response 저장 |
| TR-003 | 음성 녹음 브라우저 호환성 | MEDIUM | MediaRecorder/Web Speech API 지원 여부 체크, 텍스트 모드 폴백 |
| TR-004 | SQLite 동시 접근 (다중 탭) | LOW | WAL 모드 활성화, 단일 사용자 |
| TR-005 | 오디오 데이터 크기 (Base64 저장) | MEDIUM | 10MB body 제한, 오래된 녹음 자동 정리 |
