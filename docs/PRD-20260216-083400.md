**버전**: 1.0
**작성일**: 2026-02-16
**상태**: Draft

## 1. 개요

### 1.1 배경
OPIc(Oral Proficiency Interview - computer) 시험은 한국에서 가장 널리 활용되는 영어 말하기 능력 평가 시험 중 하나로, 취업·승진·해외파견 등 다양한 목적으로 응시 수요가 꾸준히 증가하고 있다. 그러나 기존 OPIc 준비 방식은 학원 수업이나 독학에 의존하며, 실제 시험과 유사한 환경에서 반복 연습하고 즉각적인 피드백을 받기 어려운 한계가 있다.

본 프로젝트는 AI 기술(Google Gemini API)을 활용하여 OPIc 시험과 유사한 환경에서 모의시험을 치르고, AI 채점 피드백을 통해 자신의 약점을 객관적으로 파악할 수 있는 개인 학습 웹 앱을 구축한다. 바이브 코딩 심화과정 3시간 실습 프로젝트로 설계되어, 수강생이 Claude Code, Google Stitch, Gemini API를 활용하여 직접 풀스택 앱을 완성하는 것을 목표로 한다.

학습자는 서베이 주제를 선택하고, 목표 레벨을 설정한 뒤, 실제 시험과 동일한 타이머 환경에서 5문제 모의시험을 진행하며, AI 피드백을 통해 예상 등급·문법·유창성·어휘 점수를 확인하고 성장 추이를 대시보드에서 추적할 수 있다.

### 1.2 목표
- 실제 OPIc 시험과 동일한 환경(타이머, 5문제 구성, 질문 유형)에서 모의시험 연습 기능 제공
- Gemini AI 기반 답변 평가로 예상 등급·문법·유창성·어휘 점수 등 객관적 피드백 제공
- 현재 레벨과 목표 레벨 간 갭 분석 및 맞춤형 학습 가이드 제공
- 학습 이력 저장 및 대시보드를 통한 성장 추이 시각화
- 3시간 실습 내 MVP 완성이 가능한 수준의 기능 범위 설계

### 1.3 범위
#### 포함 범위
- 서베이 주제 선택/관리 (10개 주제, 3~5개 선택)
- OPIc 레벨 설정 (NL~AL 9단계, 현재/목표 레벨)
- 주제별 문제은행 및 답변 가이드
- 5문제 모의시험 (타이머, 텍스트 입력, 자동 진행)
- Gemini AI 기반 답변 평가 및 피드백 시각화
- 학습 대시보드 (통계, 점수 추이, 시험 이력)
- 하단 탭바 기반 네비게이션
- SQLite 로컬 데이터 저장

#### 범위 외
- 음성 녹음/재생 기능 (확장 기능)
- 모바일 반응형 레이아웃 (P3)
- 사용자 로그인/인증 기능 (단일 사용자 로컬 앱)
- 다국어 인터페이스 (한국어 UI 고정, 질문/답변만 영어)
- 데이터 내보내기/가져오기 (P3)
- 유료 AI 모델 연동

### 1.4 대상 사용자
| 사용자 유형 | 역할 및 주요 활동 |
|------------|------------------|
| OPIc 학습자 | 20~40대 한국인 OPIc 시험 준비생. IM1~IH 레벨을 목표로 서베이 주제 선택, 모의시험 응시, AI 피드백 확인, 성장 추적 |
| 바이브 코딩 수강생 | 비개발자. 3시간 실습에서 AI 도구(Claude Code, Stitch, Gemini)를 활용해 앱을 직접 구축하는 개발 학습자 |
| 강사 | 바이브 코딩 심화과정 진행자. 요구사항 정의서를 기반으로 수강생의 앱 개발을 가이드 |

### 1.5 성공 지표
- MVP 기능(P1 22개) 3시간 내 구현 완료율 80% 이상
- 모의시험 1회 완료 후 AI 피드백 정상 수신율 95% 이상
- Gemini API 응답 시간 15초 이내 달성
- 페이지 전환 속도 0.5초 이내 달성
- 학습 이력 데이터 저장/복원 정확도 100%

## 2. 기능 요구사항 (Functional Requirements)

### FR-001: 주제 목록 표시
**우선순위**: HIGH
**설명**: OPIc 시험에 출제되는 10개 주제(자기소개, 집/이웃, 여가활동, 여행, 운동/스포츠, 음악/영화, 요리/음식, 기술/인터넷, 교육, 직장/업무)를 카드 형태로 화면에 표시한다.

**User Story**: OPIc 학습자로서, 나는 시험에 출제되는 주제 목록을 한눈에 보고 싶다, 관심 주제를 선택하기 위해.

**Acceptance Criteria**:
- [ ] 10개 주제가 카드 그리드 형태로 표시된다
- [ ] 각 카드에 주제명(한국어)과 아이콘이 표시된다
- [ ] 카드 레이아웃이 다크 모드 디자인 가이드에 맞게 렌더링된다

**출처**: OPIc_Master_요구사항_정의서.txt:FR-001 (2.1 서베이 설정 기능)

---

### FR-002: 주제 선택/해제
**우선순위**: HIGH
**설명**: 사용자가 주제 카드를 탭하여 선택/해제할 수 있다. 최소 3개, 최대 5개까지 선택 가능하며, 범위를 벗어나면 선택이 제한된다.

**User Story**: OPIc 학습자로서, 나는 관심 있는 주제 3~5개를 선택하고 싶다, 해당 주제 중심으로 모의시험을 보기 위해.

**Acceptance Criteria**:
- [ ] 카드 탭 시 선택 상태가 토글된다 (선택 시 틸 컬러 하이라이트)
- [ ] 선택 개수가 실시간으로 표시된다
- [ ] 5개 초과 선택 시 추가 선택이 차단되고 안내 메시지가 표시된다
- [ ] 3개 미만 선택 상태에서 저장 버튼이 비활성화된다

**출처**: OPIc_Master_요구사항_정의서.txt:FR-002 (2.1 서베이 설정 기능)

---

### FR-003: 선택 결과 저장
**우선순위**: HIGH
**설명**: 사용자가 선택한 주제를 SQLite DB에 저장한다. 단일 사용자 앱이므로 기존 선택을 덮어쓴다.

**User Story**: OPIc 학습자로서, 나는 선택한 주제가 저장되길 원한다, 다음 접속 시 다시 선택하지 않기 위해.

**Acceptance Criteria**:
- [ ] 저장 버튼 클릭 시 선택된 주제가 survey_topics 테이블에 반영된다
- [ ] 기존 선택이 새로운 선택으로 덮어쓰기된다
- [ ] 저장 성공 시 확인 피드백이 표시된다

**출처**: OPIc_Master_요구사항_정의서.txt:FR-003 (2.1 서베이 설정 기능)

---

### FR-004: 선택 결과 불러오기
**우선순위**: HIGH
**설명**: 앱 시작 시 이전에 선택한 주제를 SQLite DB에서 자동 로드하여 화면에 반영한다.

**User Story**: OPIc 학습자로서, 나는 앱을 다시 열었을 때 이전 선택이 유지되길 원한다, 매번 다시 설정하지 않기 위해.

**Acceptance Criteria**:
- [ ] 서베이 설정 화면 진입 시 DB에서 이전 선택을 자동 로드한다
- [ ] 이전에 선택한 주제 카드가 선택 상태로 표시된다
- [ ] 저장된 데이터가 없으면 모든 카드가 미선택 상태로 표시된다

**출처**: OPIc_Master_요구사항_정의서.txt:FR-004 (2.1 서베이 설정 기능)

---

### FR-005: 주제별 질문 목록 표시
**우선순위**: HIGH
**설명**: 사용자가 선택한 주제에 해당하는 예상 질문을 목록으로 표시한다. 주제당 최소 5개 이상의 질문이 제공된다.

**User Story**: OPIc 학습자로서, 나는 선택한 주제의 예상 질문을 확인하고 싶다, 시험에 나올 질문을 미리 대비하기 위해.

**Acceptance Criteria**:
- [ ] 선택한 주제별 탭으로 질문 목록이 구분된다
- [ ] 각 주제당 최소 5개 이상의 질문이 표시된다
- [ ] 질문 텍스트가 영어로 표시된다

**출처**: OPIc_Master_요구사항_정의서.txt:FR-005 (2.2 문제은행 기능)

---

### FR-006: 질문 유형 분류
**우선순위**: HIGH
**설명**: 각 질문에 유형 태그(서베이 질문 / 콤보 질문 / 롤플레이 / 돌발 질문)를 표시하여 질문 유형을 구분한다.

**User Story**: OPIc 학습자로서, 나는 각 질문의 유형을 알고 싶다, 유형별 답변 전략을 다르게 준비하기 위해.

**Acceptance Criteria**:
- [ ] 각 질문에 유형 태그(서베이/콤보/롤플레이/돌발)가 표시된다
- [ ] 유형별로 시각적 구분이 가능하다 (색상 또는 아이콘)
- [ ] 유형 필터링 기능이 제공된다

**출처**: OPIc_Master_요구사항_정의서.txt:FR-006 (2.2 문제은행 기능)

---

### FR-007: 답변 가이드 제공
**우선순위**: MEDIUM
**설명**: 각 질문에 대한 답변 구조 가이드(도입-본론-마무리), 핵심 표현, 목표 단어 수를 제공한다.

**User Story**: OPIc 학습자로서, 나는 각 질문에 어떻게 답변하면 좋은지 가이드를 보고 싶다, 답변 구조를 학습하기 위해.

**Acceptance Criteria**:
- [ ] 질문 상세 화면에서 추천 답변 구조(도입-본론-마무리)가 표시된다
- [ ] 핵심 표현(key phrases)이 목록으로 제공된다
- [ ] 해당 질문의 목표 단어 수가 표시된다

**출처**: OPIc_Master_요구사항_정의서.txt:FR-007 (2.2 문제은행 기능)

---

### FR-008: 레벨별 가이드 분기
**우선순위**: MEDIUM
**설명**: 사용자의 목표 레벨에 따라 다른 수준의 답변 가이드를 제공한다. IM1 목표 시 간단한 표현, IH 목표 시 복잡한 구조와 관용어구를 포함한다.

**User Story**: OPIc 학습자로서, 나는 내 목표 레벨에 맞는 가이드를 보고 싶다, 수준에 맞게 학습하기 위해.

**Acceptance Criteria**:
- [ ] 사용자 설정의 목표 레벨에 따라 가이드 내용이 달라진다
- [ ] 낮은 레벨(IM1)은 간단한 표현, 높은 레벨(IH)은 복잡한 구조를 제공한다
- [ ] answer_guides 테이블에서 level_code 기반으로 가이드를 조회한다

**출처**: OPIc_Master_요구사항_정의서.txt:FR-008 (2.2 문제은행 기능)

### FR-009: 현재 레벨 선택
**우선순위**: HIGH
**설명**: NL~AL 9단계(NL, NM, NH, IL, IM1, IM2, IM3, IH, AL) 중 사용자의 현재 실력 레벨을 선택할 수 있다.

**User Story**: OPIc 학습자로서, 나는 나의 현재 OPIc 레벨을 설정하고 싶다, 목표와의 차이를 파악하기 위해.

**Acceptance Criteria**:
- [ ] 9단계 레벨이 시각적으로 나열된다
- [ ] 하나의 레벨만 선택 가능하다
- [ ] 선택한 레벨이 시각적으로 강조된다

**출처**: OPIc_Master_요구사항_정의서.txt:FR-009 (2.3 레벨 설정 기능)

### FR-010: 목표 레벨 선택
**우선순위**: HIGH
**설명**: NL~AL 9단계 중 목표 레벨을 선택한다. 목표 레벨은 현재 레벨 이상이어야 하며 유효성 검사를 수행한다.

**User Story**: OPIc 학습자로서, 나는 달성하고 싶은 목표 레벨을 설정하고 싶다, 학습 방향을 명확히 하기 위해.

**Acceptance Criteria**:
- [ ] 목표 레벨 선택 시 현재 레벨보다 낮은 레벨은 선택 불가하다
- [ ] 잘못된 선택 시 유효성 검사 에러 메시지가 표시된다
- [ ] 유효한 목표 레벨만 활성화 상태로 표시된다

**출처**: OPIc_Master_요구사항_정의서.txt:FR-010 (2.3 레벨 설정 기능)

### FR-011: 레벨 갭 분석 표시
**우선순위**: HIGH
**설명**: 현재 레벨에서 목표 레벨까지의 단계 수, 예상 학습 기간, 필요 역량을 시각적 프로그레스 바와 텍스트로 표시한다.

**User Story**: OPIc 학습자로서, 나는 현재 레벨과 목표 레벨의 차이를 시각적으로 보고 싶다, 학습 계획을 세우기 위해.

**Acceptance Criteria**:
- [ ] 현재→목표 간 단계 수가 숫자로 표시된다
- [ ] 프로그레스 바에 현재 위치와 목표 위치가 시각화된다
- [ ] 예상 학습 기간과 필요 역량 텍스트가 표시된다

**출처**: OPIc_Master_요구사항_정의서.txt:FR-011 (2.3 레벨 설정 기능)

**User Story**: OPIc 학습자로서, 나는 각 레벨에 필요한 답변 분량을 알고 싶다, 충분한 양을 작성하도록 연습하기 위해.

**Acceptance Criteria**:
- [ ] 각 레벨 옆에 최소 권장 단어 수가 표시된다
- [ ] levels 테이블의 min_words 값을 기반으로 표시된다

**출처**: OPIc_Master_요구사항_정의서.txt:FR-012 (2.3 레벨 설정 기능)

### FR-014: 시험 시작

## 4. 제약조건

### CON-001: 개발 시간 제한
**설명**: 3시간 실습 내 MVP(최소 기능 제품) 완성이 가능해야 한다. P1 기능 22개가 3시간 내 구현 대상이다.

### CON-002: 무료 서비스만 사용
**설명**: 외부 유료 서비스 사용이 금지되며, Gemini API 무료 티어(15 RPM, 1,000 RPD)만 사용한다.

### CON-003: 단일 사용자 로컬 앱
**설명**: 로그인/인증 기능 없이 단일 사용자 로컬 환경에서 동작한다. SQLite 파일 기반 저장소를 사용한다.

### CON-004: 텍스트 기반 답변
**설명**: 음성 녹음/재생은 MVP 범위 외이며, 답변은 텍스트 입력만 지원한다.

### CON-005: 기술 스택 고정
**설명**: 프론트엔드는 HTML/CSS/JavaScript, 데이터베이스는 SQLite, AI는 Gemini API(gemini-2.5-flash-lite), UI 디자인은 Google Stitch, 코딩 도구는 Claude Code로 고정한다.
