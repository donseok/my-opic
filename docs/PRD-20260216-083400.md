## 1. 개요

### 1.1 배경
OPIc(Oral Proficiency Interview - computer) 시험은 한국에서 가장 널리 활용되는 영어 말하기 능력 평가 시험 중 하나로, 취업·승진·해외파견 등 다양한 목적으로 응시 수요가 꾸준히 증가하고 있다. 그러나 기존 OPIc 준비 방식은 학원 수업이나 독학에 의존하며, 실제 시험과 유사한 환경에서 반복 연습하고 즉각적인 피드백을 받기 어려운 한계가 있다.

본 프로젝트는 AI 기술(Google Gemini API)을 활용하여 OPIc 시험과 유사한 환경에서 모의시험을 치르고, AI 채점 피드백을 통해 자신의 약점을 객관적으로 파악할 수 있는 종합 학습 웹+모바일 앱을 구축한다.

학습자는 서베이 주제를 선택하고, 목표 레벨을 설정한 뒤, 실제 시험과 동일한 타이머 환경에서 5문제 모의시험을 진행하며, AI 피드백을 통해 예상 등급·문법·유창성·어휘·과제 완성도·내용 전달력 점수를 확인하고 성장 추이를 대시보드에서 추적할 수 있다. 또한 스크립트 빌더, 단어장, SRS 간격반복 복습, 문장별 발음 연습 등 종합적인 학습 도구를 제공한다.

### 1.2 목표
- 실제 OPIc 시험과 동일한 환경(타이머, 5문제 구성, 질문 유형)에서 모의시험 연습 기능 제공
- Gemini AI 기반 답변 평가로 예상 등급·문법·유창성·어휘·과제 완성도·내용 전달력 점수 등 객관적 피드백 제공
- 현재 레벨과 목표 레벨 간 갭 분석 및 맞춤형 학습 가이드 제공
- 학습 이력 저장 및 대시보드를 통한 성장 추이 시각화
- 스크립트 빌더(AI 생성/개선), 단어장(플래시카드), SRS 간격반복 복습 제공
- 음성 녹음 + AI 멀티모달 분석(발음·유창성·억양 평가) 지원
- 일일 학습 플랜 자동 생성 및 출석/포인트 동기부여 시스템
- Flutter 모바일 앱으로 동일 API 기반 크로스 플랫폼 지원

### 1.3 범위
#### 포함 범위
- 서베이 주제 선택/관리 (10개 주제, 3~5개 선택)
- OPIc 레벨 설정 (NL~AL 9단계, 현재/목표 레벨)
- 주제별 문제은행 및 답변 가이드 (레벨별 분기)
- 5문제 모의시험 (타이머, 텍스트+음성 입력, 자동 진행)
- Gemini AI 기반 답변 평가 및 피드백 시각화 (5축 레이더 차트)
- 스크립트 빌더 (초안 작성 → AI 생성 → AI 개선 → 플래시카드 암기)
- 주제별 단어장 (플래시카드 모드 / 리스트 모드 + TTS)
- SRS 간격반복 복습 (SM-2 알고리즘)
- 일일 학습 플랜 자동 생성 (약점 분석 기반)
- 음성 녹음 및 AI 음성 분석 (발음·유창성·억양·속도·필러 워드)
- 문장별 발음 연습 (스크립트 문장 단위 녹음/AI 평가)
- 출석 체크 및 학습 포인트 시스템
- 학습 시간 추적
- 학습 대시보드 (통계, 점수 추이, 시험 이력, 5축 레이더)
- 하단 탭바 기반 네비게이션 (10개 탭)
- SQLite 로컬 데이터 저장
- Flutter 모바일 앱 (Android/iOS)

#### 범위 외
- 사용자 로그인/인증 기능 (단일 사용자 로컬 앱)
- 다국어 인터페이스 (한국어 UI 고정, 질문/답변만 영어)
- 데이터 내보내기/가져오기
- 클라우드 동기화
- 결제/구독 시스템

### 1.4 대상 사용자
| 사용자 유형 | 역할 및 주요 활동 |
|------------|------------------|
| OPIc 학습자 | 20~40대 한국인 OPIc 시험 준비생. IM1~IH 레벨을 목표로 서베이 주제 선택, 모의시험 응시, AI 피드백 확인, 스크립트 암기, 단어 학습, SRS 복습, 성장 추적 |

### 1.5 성공 지표
- 모의시험 1회 완료 후 AI 피드백 정상 수신율 95% 이상
- Gemini API 응답 시간 15초 이내 달성
- 페이지 전환 속도 0.5초 이내 달성
- 학습 이력 데이터 저장/복원 정확도 100%
- 일일 학습 플랜 자동 생성 정상 작동률 95% 이상
- 음성 녹음 및 AI 분석 정상 동작률 90% 이상

## 2. 기능 요구사항 (Functional Requirements)

### 2.1 서베이 설정 기능

#### FR-001: 주제 목록 표시
**우선순위**: HIGH | **상태**: ✅ 완료
OPIc 시험에 출제되는 10개 주제를 카드 형태로 화면에 표시한다.

#### FR-002: 주제 선택/해제
**우선순위**: HIGH | **상태**: ✅ 완료
사용자가 주제 카드를 탭하여 선택/해제할 수 있다. 최소 3개, 최대 5개까지 선택 가능.

#### FR-003: 선택 결과 저장
**우선순위**: HIGH | **상태**: ✅ 완료
선택한 주제를 SQLite DB에 저장. 단일 사용자 앱이므로 기존 선택을 덮어쓴다.

#### FR-004: 선택 결과 불러오기
**우선순위**: HIGH | **상태**: ✅ 완료
앱 시작 시 이전 선택한 주제를 자동 로드하여 화면에 반영.

### 2.2 문제은행 기능

#### FR-005: 주제별 질문 목록 표시
**우선순위**: HIGH | **상태**: ✅ 완료
선택한 주제에 해당하는 예상 질문을 주제별 탭으로 구분하여 목록 표시. 주제당 최소 5개 질문.

#### FR-006: 질문 유형 분류
**우선순위**: HIGH | **상태**: ✅ 완료
각 질문에 유형 태그(서베이/콤보/롤플레이/돌발) 표시 및 필터링.

#### FR-007: 답변 가이드 제공
**우선순위**: MEDIUM | **상태**: ✅ 완료
각 질문에 대한 답변 구조 가이드(도입-본론-마무리), 핵심 표현, 목표 단어 수 제공.

#### FR-008: 레벨별 가이드 분기
**우선순위**: MEDIUM | **상태**: ✅ 완료
목표 레벨에 따라 다른 수준의 답변 가이드 제공. answer_guides 테이블 level_code 기반.

### 2.3 레벨 설정 기능

#### FR-009: 현재 레벨 선택
**우선순위**: HIGH | **상태**: ✅ 완료
NL~AL 9단계 중 현재 실력 레벨 선택.

#### FR-010: 목표 레벨 선택
**우선순위**: HIGH | **상태**: ✅ 완료
목표 레벨 선택 (현재 레벨 이상만 선택 가능, 유효성 검사).

#### FR-011: 레벨 갭 분석 표시
**우선순위**: HIGH | **상태**: ✅ 완료
현재→목표 레벨 간 단계 수, 프로그레스 바, 예상 학습 기간 시각화.

#### FR-012: 레벨별 최소 단어 수 표시
**우선순위**: MEDIUM | **상태**: ✅ 완료
각 레벨의 최소 권장 단어 수 안내.

#### FR-013: 레벨 설정 저장
**우선순위**: HIGH | **상태**: ✅ 완료
현재/목표 레벨을 user_settings 테이블에 저장.

### 2.4 모의시험 기능

#### FR-014: 시험 시작
**우선순위**: HIGH | **상태**: ✅ 완료
서베이 주제 + 레벨 설정 완료 후 시험 시작 가능. TTS로 문제 읽기 기능 포함.

#### FR-015: 문제 구성 (5문제)
**우선순위**: HIGH | **상태**: ✅ 완료
서베이 기반 4문제 + 롤플레이 1문제 랜덤 자동 구성.

#### FR-016: 준비 시간 타이머
**우선순위**: HIGH | **상태**: ✅ 완료
각 문제 시작 전 8초 카운트다운 (원형 SVG 타이머).

#### FR-017: 답변 시간 타이머
**우선순위**: HIGH | **상태**: ✅ 완료
서베이 90초/롤플레이 120초 카운트다운. 30초 미만 시 경고색.

#### FR-018: 답변 텍스트 입력
**우선순위**: HIGH | **상태**: ✅ 완료
텍스트 입력 + 실시간 단어 수 카운트.

#### FR-018b: 답변 음성 입력 (STT)
**우선순위**: MEDIUM | **상태**: ✅ 완료
Web Speech API 기반 음성인식으로 답변 자동 입력. 텍스트/음성 모드 전환 가능.

#### FR-019: 목표 대비 달성률 표시
**우선순위**: MEDIUM | **상태**: ✅ 완료
현재 단어 수 / 목표 단어 수 비율 프로그레스 바 표시.

#### FR-020: 다음 문제 이동
**우선순위**: HIGH | **상태**: ✅ 완료
답변 시간 종료 또는 "다음" 버튼으로 다음 문제 이동.

#### FR-021: 시험 완료 처리
**우선순위**: HIGH | **상태**: ✅ 완료
5문제 완료 후 결과 요약. exam_sessions + exam_answers 테이블에 저장.

### 2.5 AI 피드백 기능

#### FR-022: AI 피드백 요청
**우선순위**: HIGH | **상태**: ✅ 완료
시험 완료 후 Gemini API에 평가 요청 (텍스트 평가).

#### FR-022b: AI 음성 분석
**우선순위**: MEDIUM | **상태**: ✅ 완료
음성 녹음 데이터를 Gemini API 멀티모달로 분석 (발음·유창성·억양·속도 평가).

#### FR-023: 시스템 프롬프트 설계
**우선순위**: HIGH | **상태**: ✅ 완료
OPIc 채점관 역할 시스템 프롬프트. JSON 형식으로 예상 등급, 5축 점수(문법/유창성/어휘/과제완성도/내용전달력), 잘한 점/개선할 점 출력.

#### FR-024: 피드백 결과 시각화
**우선순위**: HIGH | **상태**: ✅ 완료
예상 등급 뱃지, 5축 레이더 차트(Chart.js), 잘한 점/개선할 점 카드, 레벨 진행 시각화.

#### FR-025: 피드백 결과 저장
**우선순위**: MEDIUM | **상태**: ✅ 완료
ai_feedbacks + skill_assessments 테이블에 저장.

#### FR-026: API 에러 처리
**우선순위**: HIGH | **상태**: ✅ 완료
429/400/500 에러 분기 처리, 재시도 버튼, Rate Limit 적용.

### 2.6 스크립트 빌더 기능

#### FR-033: 스크립트 초안 작성
**우선순위**: MEDIUM | **상태**: ✅ 완료
질문 선택 후 답변 스크립트 초안 텍스트 입력.

#### FR-034: AI 스크립트 생성
**우선순위**: MEDIUM | **상태**: ✅ 완료
`POST /scripts/generate` — Gemini AI로 목표 레벨에 맞는 스크립트 자동 생성.

#### FR-035: AI 스크립트 개선
**우선순위**: MEDIUM | **상태**: ✅ 완료
`POST /scripts/:id/refine` — 기존 스크립트를 AI로 문법/유창성/어휘 개선.

#### FR-036: 플래시카드 암기
**우선순위**: MEDIUM | **상태**: ✅ 완료
스크립트를 문장 단위로 쪼개어 플래시카드 형태로 암기 연습.

#### FR-037: 문장별 발음 연습
**우선순위**: LOW | **상태**: ✅ 완료
스크립트 문장 단위로 녹음하여 AI 발음 평가. sentence_practices 테이블에 기록.

주제별 핵심 단어/표현을 topic_vocabulary 테이블에서 조회. 카드 모드/리스트 모드 전환.

## 3. 비기능 요구사항 (Non-Functional Requirements)

### NFR-001: 성능
페이지 전환 0.5초 이내, Gemini API 응답 대기 최대 15초(로딩 인디케이터 표시), 타이머 정확도 ±0.5초 이내.

### NFR-002: 보안
- Gemini API Key는 .env 파일로 관리, 백엔드 프록시를 통해 호출
- API Rate Limit 적용 (분당 100회)
- SQL 인젝션 방지 (prepared statement)
- XSS 방지 (innerHTML 금지, createElement+textContent만 사용)

### NFR-003: 사용성
라이트 모드 기본, 직관적 UI. 인터페이스는 한국어, OPIc 질문/답변은 영어.

### NFR-004: 호환성
- Chrome 최신 버전 기준 (데스크톱 + 모바일)
- Flutter 앱: Android/iOS 지원
- Web Speech API 지원 브라우저에서 음성 기능 활성화

### NFR-005: 데이터 무결성
SQLite WAL 모드 + 트랜잭션으로 데이터 저장 보장. 재시작 시 모든 데이터 유지.

### NFR-006: 유지보수성
기능별 파일 분리 (모듈-탭 1:1 매핑). 한국어 주석.

## 4. 제약조건

### CON-001: 무료 서비스만 사용
Gemini API 무료 티어 사용 (gemini-2.5-flash).

### CON-002: 단일 사용자 로컬 앱
로그인/인증 없이 단일 사용자 로컬 환경에서 동작. SQLite 파일 기반.

### CON-003: 기술 스택 고정
- **Backend**: Node.js 20 + Express 4 + better-sqlite3
- **Web Frontend**: Vanilla JS SPA (프레임워크 사용 금지), Chart.js 4, Lucide Icons
- **Mobile**: Flutter (Dart), fl_chart, provider 패턴
- **AI**: Google Gemini API (gemini-2.5-flash), node-fetch, 텍스트+오디오 멀티모달

## 7. 용어 정의

| 용어 | 정의 |
|------|------|
| OPIc | Oral Proficiency Interview - computer. 컴퓨터 기반 영어 말하기 시험 |
| NL~AL | 9단계 레벨: NL, NM, NH, IL, IM1, IM2, IM3, IH, AL |
| 서베이 | OPIc 시험 시작 전 응시자가 선택하는 관심 주제 설문 |
| 콤보 질문 | 하나의 질문에 2~3개 소질문이 포함된 복합 질문 |
| 롤플레이 | 특정 상황을 가정하고 역할 수행하는 문제 유형 |
| 돌발 질문 | 서베이 주제와 무관한 예상치 못한 질문 |
| SRS | Spaced Repetition System. 간격반복 학습 시스템 |
| SM-2 | SuperMemo 2 알고리즘. SRS에서 사용하는 간격 계산 알고리즘 |
| TTS | Text-to-Speech. 텍스트를 음성으로 읽어주는 기능 |
| STT | Speech-to-Text. 음성을 텍스트로 변환하는 기능 |
| Gemini API | Google의 AI 모델 API. 답변 평가 + 음성 분석에 사용 |
